# OGKS-Ozel_Gereksinim_Kayit_Sistemi-

## 📌 Projenin Amacı
Özel gereksinimli bireylerin (otizm, fiziksel, zihinsel) sağlık, eğitim ve günlük kriz verilerini tek bir merkezde toplayan kurumsal bir altyapıdır. Sistem; aileyi, doktoru ve özel eğitimciyi izole verilerden kurtarıp aynı veritabanında buluşturur.
